# SHA256
This repository contains a simple implementation of the SHA256 hashing algorithm

## Usage
The algorithm can be used by including the sha256.h header file. This will allow you to call the sha256 function directly. The function
takes in a null-terminated string as input and produces a null-terminated string as output (formatted as a hex string).

Alternatively, you can compile and run it as a standalone program. It will take one argument, the string you want to hash, and will print
the resulting hash to the standard output.
